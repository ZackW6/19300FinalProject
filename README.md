This isn't a new problem, but something that I've wanted to do, and is helpful personally. For testing web apps, I would usually use my computer, but after that they are never going anywhere. I wan't to be able to publish apps, and have a domain of my own to publish many games and such.

I have an old personal computer, I want to host a personal website, and make a framework for posting multiple apps in subfolders of a given domain. Ideally I would make a central posting subfolder, and then online folders could be sent, and activated.

I will probably use an ubuntu server, with cloudflare domain. I will probably have to use react for js libraries that allow me to send large messages. Data will be stored in the literal folders it is sent in, such that it can be run.
